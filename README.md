# Medicare Wish
### AI-Based Medical Report Analyzer

Medicare Wish is an AI-powered healthcare prototype designed to help patients
understand medical lab reports by identifying abnormal values and presenting
simple explanations.

## Problem
Medical reports are complex and difficult for non-medical users to interpret.

## Solution
The system analyzes report values using standard medical ranges and classifies
them as Normal, High, or Low.

## Tech Stack
- Python (Flask)
- HTML, CSS
- Rule-based AI logic

## How to Run
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run the app: python app.py
4. Open browser at http://127.0.0.1:5000/
